+PLUS setup test page

Builds GrapheneOS with +PLUS for your phone, signed with a key only you hold, and loads it over USB. Everything happens in this browser: nothing is uploaded.

Before you start

    You need: the phone (with its own Android or with GrapheneOS), a USB cable, a place to keep a secret (a password manager or a printed sheet in a safe place), and about an hour. The phone is loaded the way GrapheneOS's own installer does it. The phone will be erased.

    Which phone?

    Phone model

    Get GrapheneOS

    Download the official GrapheneOS update file for your phone from GrapheneOS's server, then choose it here. When loading, the page also gets the matching firmware and install steps for that release from GrapheneOS's server, and checks the firmware against this file.

      Your key

      +PLUS signs every update for your phone with this key. Whoever has it can make your phone accept an update, but still can't unlock it without your PIN. Save the backup now: it is the only copy, and nobody can recover it for you.

        Last steps on the phone
        
      
          
        
        1. The phone restarts and erases itself. Go through GrapheneOS setup and set a PIN or password.
          2. 
        
        2. Open +PLUS (Settings > System > System update) and tap Import your key, then scan this code.
          3. 
        
        3. Then, in Developer options, turn OEM unlocking off. With it off, nobody can unlock the bootloader

        What this is
        
    
        The key that signs every update for your phone. With it, someone could sign updates for your phone, but could not
      unlock the phone without your PIN or password. Without it, a phone that stops starting can only be recovered by
      erasing it.
        
    
        How to use it
        
    
        In +PLUS, tap Import your key and scan the code above, or type the backup text. The setup page's
      "I already have a +PLUS key backup" accepts the text too.
