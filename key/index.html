Key backup converter

From a +PLUS key backup to standard key files

+PLUS home Set up a phone Using the files

Paste your PLUSKEY1-… backup to get your key as ordinary files: a private key that avbroot and OpenSSL read, the update certificate your phone trusts, and the verified-boot key blob that fastboot installs.

This page runs entirely in your browser: nothing you paste is sent anywhere or stored. For the most care, load the page, then disconnect from the network before you paste. The private key file is as powerful as the backup itself: anyone who has it can sign updates your phone accepts.

Your key files

Key fingerprint: . +PLUS shows the same fingerprint in its key screen.

owner.key: private key

RSA-4096 in PKCS#8 PEM, without a password. Encrypt it if you keep it on a computer: openssl pkcs8 -topk8 -v2 aes-256-cbc -in owner.key -out owner-encrypted.key.

owner.crt: update certificate

The X.509 certificate updates are signed against (avbroot's --cert-ota). It is derived from the key, so it is always the same one your phone already trusts.

avb_pkmd.bin: verified-boot public key

The key blob the bootloader checks images with (fastboot flash avb_custom_key avb_pkmd.bin, avbroot's --public-key-avb).

Using the files

+PLUS signs both verified boot and updates with this one key. With avbroot on a computer you can, for example, build an image from an official GrapheneOS update yourself:

avbroot ota patch --input tokay-ota_update-2026102100.zip --rootless \
  --key-avb owner.key --key-ota owner.key --cert-ota owner.crt \
  --output signed.zip

avbroot ota verify --input signed.zip --public-key-avb avb_pkmd.bin --cert-ota owner.crt

An image built this way is GrapheneOS without +PLUS's additions: +PLUS normally adds itself and your plus-ups before signing. Use it for recovery and checks; for everyday updates, let +PLUS do it on the phone.

To check a key file with OpenSSL: openssl pkey -in owner.key -noout -text | head and openssl x509 -in owner.crt -noout -subject -dates.
